# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
through GitHub's "Report a vulnerability" button (Security tab > Advisories) on
https://github.com/ailtonloures/system-cli, or by email to
ailton.loures99@gmail.com.

Include the affected tool (`bin/...`), the version (`--version`), reproduction
steps and the impact you observed.

## Disclosure policy

- You will get an acknowledgement within 7 days.
- We aim to ship a fix within 90 days of the report and will coordinate the
  disclosure date with you.
- Fixes are noted in `CHANGELOG.md`; reporters are credited unless they prefer
  to stay anonymous.

## Supported versions

Only the latest release receives security fixes.
